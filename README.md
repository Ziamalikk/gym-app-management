# Gym Management App

A simple **Gym Management Application** built using **React** that allows gym administrators and users to manage gym members, packages, and payments. This is a CRUD application where all operations (Create, Read, Update, Delete) are handled on the frontend using React, with no backend integration.

## Features

- **Member Management**: Add, edit, and delete gym members.
- **Responsive UI**: The app is built with a mobile-friendly UI using **Tailwind CSS** for styling.
- **No Backend**: All data is handled locally using React state (i.e., no backend or database).
- **CRUD Operations**: Create, read, update, and delete data for members, packages, and payments.

## Technologies Used

- **Frontend**: React, Tailwind CSS, React Hooks, React Router
- **Styling**: Tailwind CSS
- **State Management**: React State (no external state management library like Redux)
- **Routing**: React Router for navigation
